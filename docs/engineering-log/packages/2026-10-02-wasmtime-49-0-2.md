# wasmtime 49.0.1 → 49.0.2 (2026-10-02)

**Why.** Eight advisories were published against 49.0.1 on 2026-10-02
(RUSTSEC-2026-0320…0327), all fixed in 49.0.2. `cargo deny check` fails on
`main` and on every open PR until this lands; it was first seen on #1041,
which touches no dependency.

**What they are.** WASI preview 0 `poll_oneoff` circumvents fuel consumption;
excessive host memory when a guest has no stdio; `fd_readdir` copies
uninitialized padding into guest memory; a pre-epoch timestamp panics the host
on wasip3; two GC heap corruptions (mis-typed tag imports, missing rooting
across `try_call`); an unvalidated async-lifted callback result count (native
stack buffer overflow); `wasi:http` panics on a zero timeout.

**Exposure here, not measured per advisory.** The engine config keeps GC,
exceptions and component-model async off (check 20's deny-list), which is
where three of the eight live. The fuel bypass and the host-memory and panic
findings are in WASI paths the worker does link. No attempt was made to prove
any one of them reachable; the patch is taken because it is the fix.

**What changed.**
* `wasmtime`, `wasmtime-wasi`, `wasmtime-wasi-http` 49.0.2 in
  `talos-worker-runtime/Cargo.toml`; the `worker` dev-dependency with them.
* `wasmtime_version!` → `49.0.2` (the boot log and the AOT fingerprint derive
  from it); the fingerprint hash re-pinned; `AOT_VERSION_HDR` → `TALOSV11`, so
  cached AOT blobs are rejected by header and recompile on next use.
* Lockfile: the wasmtime, cranelift (0.136.1 → 0.136.2) and wasm-tools
  (0.258.0 → 0.258.3) families. Nothing else moved.
* `docs/wasmtime-version-tracking.md`.

**Behavioural review.** The 49.0.2 release notes list the eight fixes and no
changed default, new option or newly enabled proposal. No engine config line
changed. The locked-down-proposal and fuel-cost tests added for 49 pass
unchanged.

**Checked.** `cargo deny check advisories` is clean. 1,018 tests across
`talos-worker-runtime` and `worker` pass. Clippy with all targets on both.

**Deploy note.** Controller and worker both link the runtime; every cached AOT
blob recompiles once after the deploy.

**Not verified.** No module was run on the deployed worker; that is the
operator's deploy.
